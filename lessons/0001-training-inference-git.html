第一课：模型怎样从代码变成比赛结果

目标：你能分清训练与推理，并在 VS Code 中完成一次测试和一次 Git 提交。

一、一个模型项目不只有两份代码

部分作用AIC v0 当前状态
数据与标签告诉训练代码输入和正确答案正式集无 bbox，只有官方单样例
训练代码计算 loss、反向传播并更新权重尚未编写
模型权重训练后学到的参数使用预训练 Florence-2
验证代码用 IoU/ACC 判断效果已经实现
推理代码冻结权重，对新 Query 预测 bbox已经实现
提交代码生成比赛要求的 JSON/ZIP已经实现

二、训练与最终检测有什么不同

训练图像模型预测与 GT 算 loss 反向传播保存新权重
比赛 RGB加载固定权重Query + 图像 预测 bbox写入 JSON

当前 baseline 是第二条流程：我们没有训练 Florence，而是加载别人已经训练好的权重做零样本推理。

三、Git 保存的不是“大文件备份”

Git 保存代码、配置和报告的版本历史。数据集、模型权重和推理输出由 .gitignore 排除。

工作区改动 → git add 暂存 → git commit 保存版本 → git tag 标记里程碑

四、你的第一次练习

  1. 在 VS Code 选择任务“AI​​C: 运行全部测试”。
  2. 打开左侧源代码管理，观察是否有未提交改动。
  3. 在终端运行 git log --oneline --decorate -5。
  4. 用自己的话回答：为什么模型权重不放进 Git？
