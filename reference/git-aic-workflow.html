AIC Git 版本速查

目的命令
查看当前改动git status
查看具体差异git diff
暂存指定文件git add 路径
暂存项目改动git add -A
保存一个版本git commit -m "feat: 描述"
查看版本历史git log --oneline --decorate --graph
标记比赛版本git tag -a v0.2.0 -m "说明"
查看某版本文件git show v0.1.0:README.md

v0.1.0  Florence RGB-only 完整闭环

v0.4.0  Query 关系重排序
